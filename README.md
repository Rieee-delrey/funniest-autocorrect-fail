One line that reads as a real autocorrect slip: a babysitter confirming with a parent, with one word very wrong.

Entry (66 characters):

> Hi Mrs. Johnson, just confirming I can kidnap your kids on Friday.

`main.py` writes that line to `/output/entry.txt`, reads it back to verify the bytes, and asserts the 1–199 character gate.

Built for the [make.fun](https://make.fun) bounty "Funniest Autocorrect Fail" ($2, top 7).
